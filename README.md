# TODO APP

A simple, clean to-do app built with React and Vite. The project focuses on a minimal task flow, quick task entry, and a voice-driven task creation experience.

## Features

- Add new tasks with a lightweight form
- Mark tasks as complete or incomplete
- Delete tasks from the list
- Search through existing tasks
- Use the voice input modal to add tasks by speaking naturally
- Keep everything stored in the browser for a smooth local demo experience
